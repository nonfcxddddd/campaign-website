# Campaign Website (Step 4)

เว็บไซต์แคมเปญหน้าเดียว 10 ส่วนตามโจทย์ Step 4 “Build the Campaign Website” รองรับทั้งมือถือและคอมพิวเตอร์

**ดูเว็บ:** https://nonfcxddddd.github.io/campaign-website/

## ตอนนี้เป็น template

- ข้อความที่มี **เส้นหยักสีม่วง** คือส่วนที่กลุ่มต้องแก้ (สีม่วงจงใจอยู่นอกชุดสีแคมเปญ จะได้ไม่ปนกับดีไซน์)
- กล่องเส้นประ “ส่วนนี้ต้องมี” สรุปว่าโจทย์ต้องการอะไรในแต่ละส่วน
- ปิดสวิตช์ “จุดที่ต้องแก้” ที่แถบเมนูด้านบน เพื่อดูหน้าตาจริงโดยไม่มีเครื่องหมาย

## ชุดสี 4 สี

แต่ละสีมีหน้าที่ของตัวเอง เรียงตามเนื้อเรื่องของเว็บ

| สี | ความหมาย | ใช้ในส่วน |
| --- | --- | --- |
| แดง | ปัญหา | 02 ปัญหา, 04 ผลกระทบ |
| เหลือง | ข้อเท็จจริง (เหมือนปากกาเน้นข้อความ) | 03 หลักฐาน, 09 อ้างอิง, ปุ่ม [1] [2] |
| เขียว | ทางออก | 05 ผู้เกี่ยวข้อง, 06 SDGs, 08 ร่วมมือ |
| ฟ้า (สีหลัก) | แคมเปญของเรา | 01 หน้าแรก, 07 แคมเปญ, 10 เครดิต |

สัดส่วนสีตามหลัก 60-30-10: พื้นขาวอมฟ้าประมาณ 60% สีฟ้าประมาณ 30% แดง เหลือง และเขียวรวมกันประมาณ 10% ส่วนสีเหลืองใช้เป็นพื้นหรือแถบเท่านั้น ไม่ใช้เป็นตัวหนังสือบนพื้นขาวเพราะอ่านยาก

## จุดที่แก้บ่อย (ทั้งหมดอยู่ใน `index.html`)

| อยากแก้ | หาคำนี้ในไฟล์ |
| --- | --- |
| เฉดสีทั้ง 4 | `--sky`, `--red`, `--yellow`, `--green` (และ `-ink`, `-tint` ของแต่ละสี) |
| สีประจำแต่ละส่วน | class `c-red`, `c-yellow`, `c-green`, `c-sky` ที่แท็ก `<section>` |
| ตัวเลขในกราฟ (ส่วนที่ 03) | `var TREND` |
| เป้าหมาย SDGs ที่เลือก (ส่วนที่ 06) | `data-goal="3"` และ `data-goal="13"` |
| เลขอ้างอิง [1] [2] ... | `href="#ref-1"` และ `id="ref-1"` |

แก้บนเว็บ GitHub ได้เลย: เปิดไฟล์ `index.html` แล้วกดไอคอนดินสอ (Edit) จากนั้นกด **Commit changes** เว็บจะอัปเดตเองภายใน 1–2 นาที
